## From a blank MacBook to a live site

[DRAFT: seven steps. The first two, to show how the commands look.]

1. Install Homebrew, which installs other software for you (and git with it).

<Expand title="show the command">

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

</Expand>

2. Install Node (runs the build tools) and the GitHub command line.

<Expand title="show the command">

```sh
brew install node gh
```

</Expand>
